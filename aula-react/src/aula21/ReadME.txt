Lembretes Finais (pontos a reforçar):

JSON Server: A importância de ter o JSON Server rodando em um terminal separado (e na porta correta, 3001) para que a API local esteja acessível.

Axios: A necessidade de instalar o Axios (npm install axios) se ainda não o tiverem.

Tailwind CSS: Que as classes className="..." são do Tailwind e que o framework precisa estar configurado no projeto para que os estilos apareçam.

Inspeção do Navegador: Usar as ferramentas de desenvolvedor do navegador (aba "Network") para ver as requisições HTTP sendo feitas.

Flexibilidade: Pode adicionar mais campos ao db.json e adaptar o componente para exibi-los.

Este código é autoexplicativo o suficiente para a atividade, e as classes do Tailwind já dão um bom visual sem a necessidade de CSS externo.
